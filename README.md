# ReplicaLoop

> A controlled Python demonstration of self-replication concepts for cybersecurity education.

## ⚠️ Safety Notice

ReplicaLoop is an educational project.
The demonstration is intentionally bounded and should not be used for
uncontrolled file or process replication.

## Features

- Demonstrates self-replication concepts
- Python 3
- Controlled execution
- Simple source code
- No external dependencies
